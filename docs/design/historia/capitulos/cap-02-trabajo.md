## Historia principal · Capítulo 2 · Cinco y un minuto

_Vuela Alto_
### Escena 1 · Cuatro y media

- **Objetivo:** Empezar a trabajar antes que nadie.
- **Obstáculo:** Adentro ya hay alguien, y no quiere ser visto.
- **Giro:** Edda duerme en el hangar.
- **Salida:** Nina espera afuera hasta las cinco. Todos los días.
```text
[FONDO: exterior-noche]
[MÚSICA: ninguna. Grillos.]
[NARRACIÓN]: Cuatro y media de la mañana. Todavía no se ve el cartel.
[ENTRA: Nina, derecha]
[GESTO: Habla bajito, de cara a la puerta cerrada.]
NINA [concentración]: ~Buenos d~~Hola, ¿cómo~Buen día. Llegué temprano. [EFECTO: texto rápido]  // ensayando la conversación antes de tenerla
NINA [ganas]: Por si las cinco era tarde.  // convenciéndose
[SFX: adentro, una lata que se abre]
[GESTO: Empuja la puerta. Cede sin llave.]
NINA [sorpresa]: ¿Ya hay alguien?  // descubriendo que no es la primera
[SALE: Nina]
[FONDO: interior-noche]
[NARRACIÓN]: Detrás del soporte del ala hay un catre. Alrededor, tres latas vacías y una manta.
[ENTRA: Edda, derecha]
[ENTRA: Nina, izquierda]
[GESTO: Se sienta de golpe en el catre. Esconde la lata detrás de la pierna.]
EDDA [en blanco]: …  // escondiendo dónde durmió ([en blanco]: ocultar)
EDDA [concentración]: La puerta abre a las cinco.  // echándola sin echarla
NINA [sorpresa]: Estaba abierta.  // diciendo lo que vio
EDDA [aburrimiento]: Abre a las cinco igual.  // cerrando el tema
[GESTO: Mira el catre una sola vez. Después, el piso.]
NINA [concentración]: Vuelvo a las cinco.  // eligiendo no haber visto nada
EDDA [cansancio]: Cinco.  // aceptando el trato sin decirlo
[SALE: Nina]
[SALE: Edda]
[FONDO: exterior-noche]
[ENTRA: Nina, derecha]
[GESTO: Se sienta en el escalón. Saca una libretita del bolsillo y tacha una línea.]
NINA [concentración]: «Buen día, Edda. Llegué temprano.» …Tachado.  // anotando la frase que no va a decir
[SFX: a las cinco en punto, el cerrojo se corre desde adentro]
[GESTO: Cuenta sesenta con los dedos. Recién ahí golpea.]
NINA [ganas]: Cinco y un minuto. Para que no parezca que esperé.  // cuidando a Edda con un minuto
[SALE: Nina]
```
### Escena 2 · La de la escoba

- **Objetivo:** Hacer bien el trabajo; Masaru, parecer entrenador.
- **Obstáculo:** Nadie les explica nada.
- **Giro:** El viejo les pone nombre, y le da a Masaru su primera frase de entrenador.
- **Salida:** Los dos tienen un lugar en el hangar, aunque no sea con su nombre.
```text
[FONDO: interior]
[MÚSICA: tema de Vuela Alto]
[NARRACIÓN]: Martes. Masaru llega a las siete y diez, con un cuaderno nuevo bajo el brazo.
[ENTRA: Nina, izquierda]
[ENTRA: Masaru, centro]
[ENTRA: Viejo, derecha]
MASARU [ganas]: Hoy llegué temprano.  // anunciando un logro
[GESTO: Lustra la pata de la silla plegable del viejo.]
NINA [concentración]: Son las siete y diez.  // corrigiéndolo sin dejar de trabajar
[GESTO: Muestra la tapa: dice «ENTRENADOR» y tres signos de pregunta.]
MASARU [cansancio]: Para mí es temprano. Y traje cuaderno nuevo. Para lo de entrenador.  // mostrando su plan
NINA [sorpresa]: ¿Qué hace un entrenador?  // preguntando lo básico
MASARU [concentración]: Exacto. Esa es la primera página.  // admitiendo que no sabe
VIEJO DURMIENTE [calma]: El del cuaderno.  // nombrándolo sin abrir los ojos
MASARU [sorpresa]: ¿Me habla a mí?  // sin saber si contestar
VIEJO DURMIENTE [calma]: Y la de la escoba.  // nombrándola a ella también
[GESTO: Aprieta la escoba como si se la hubieran regalado.]
NINA [alegría]: Tengo nombre.  // recibiendo un lugar
MASARU [fastidio]: Yo ya tenía nombre. Es Masaru.  // reclamando lo suyo
[GESTO: Ronca.]
VIEJO DURMIENTE [en blanco]: …  // durmiéndose para no discutir ([en blanco]: dormido)
[GESTO: Se agacha junto a la silla, con el lápiz listo.]
MASARU [concentración]: Señor. Una sola pregunta. ¿Qué le dice uno a una corredora antes de volar?  // pidiendo un consejo de verdad
VIEJO SABIO [calma]: El viento no avisa. Pero la ropa tendida sí.  // dejando una frase para dentro de mucho
[GESTO: Lo escribe con letra grande y lo subraya.]
MASARU [concentración]: Anotado.  // tomándolo en serio
NINA [sorpresa]: ¿Qué quiere decir?  // esperando la explicación
MASARU [cansancio]: Ni idea. Pero es lo primero que anoto que suena a entrenador.  // aceptando lo que tiene
[SALE: Viejo]
```
### Escena 3 · Día de paga

- **Objetivo:** Cobrar la primera semana.
- **Obstáculo:** Vuela Alto no tiene plata.
- **Giro:** Edda les paga con su premio, el que era para el hombro.
- **Salida:** Nina carga lo pesado sin que se lo pidan.
```text
[NARRACIÓN]: Viernes. Edda deja dos sobres sobre el cajón rojo, sin decir nada.
[ENTRA: Edda, derecha]
[GESTO: Abre el sobre. Cuenta. Vuelve a contar.]
MASARU [ganas]: Una pregunta sobre la paga… Ah. Ya está acá.  // llegando tarde a su propia pregunta
MASARU [sorpresa]: ¿Esto es la paga o la propina?  // midiendo lo que no alcanza
EDDA [aburrimiento]: Es lo que hay.  // sin pedir disculpas
[GESTO: Da vuelta el sobre.]
NINA [concentración]: Este sobre tiene un sello. «Premio. Cuarto puesto».  // leyendo lo que no tenía que leer
EDDA [fastidio]: Lo reciclo. Los sobres son caros. [EFECTO: globo que tarda]  // tapando el gesto con un chiste
VIEJO DURMIENTE [calma]: Edda. Ese premio era para el hombro.  // diciendo la verdad desde el rincón
EDDA [fastidio]: Duérmete, viejo.  // cerrando la puerta que abrió el viejo
> [ELECCIÓN] Qué hace Masaru con el sobre
> [ACEPTAR] Gracias. En serio.
> [RECHAZAR] No lo quiero. Úsalo para el hombro.
> [DESVIAR] ¿El cuarto puesto paga en cuotas?

(si ACEPTAR)
EDDA [aburrimiento]: No te acostumbres.  // agradeciendo al revés

(si RECHAZAR)
[GESTO: Le devuelve el sobre contra el pecho.]
EDDA [fastidio]: No es para ti. Es para que vuelvas el lunes.  // negándose a recibir ayuda

(si DESVIAR)
[GESTO: Casi sonríe. No llega.]
EDDA [aburrimiento]: En cuotas pagan del tercero para arriba.  // devolviéndole el chiste
NINA [ganas]: ¿Qué hay que cargar hoy?  // ofreciéndose antes de que Edda se mueva
EDDA [concentración]: Nada. Yo cargo.  // defendiendo el hombro que no nombra
[GESTO: Levanta la caja de herramientas antes que Edda. Pesa más de lo que parece.]
NINA [concentración]: Ya está cargado.  // cargando lo pesado para que ella no lo haga
EDDA [en blanco]: …  // sin poder negarse sin hablar del hombro ([en blanco]: ocultar)
EDDA [concentración]: Por el soporte. No por el borde.  // aceptando la ayuda con una orden
[SALE: Edda]
[SALE: Masaru]
[SALE: Nina]
```
### Escena 4 · Arriba

- **Objetivo:** Terminar la semana; Masaru, anotar «lo que vea».
- **Obstáculo:** Masaru no sabe qué mirar y Nina no levanta la vista del piso.
- **Giro:** Nina ve a Edda sonreír en el aire.
- **Salida:** No se lo cuenta a nadie.
```text
[FONDO: exterior-tarde]
[NARRACIÓN]: Al atardecer, Edda da tres vueltas sobre el campo. Masaru mira desde abajo, con el cuaderno abierto.
[ENTRA: Nina, izquierda]
[ENTRA: Masaru, centro]
[GESTO: Escribe sin mirar la hoja.]
MASARU [concentración]: Edda vuela. Hay viento. Hay una vaca.  // anotando literalmente lo que ve
[GESTO: Barre la entrada sin levantar la vista.]
NINA [concentración]: ¿Hay ropa tendida?  // ayudándolo con lo único que oyó
MASARU [sorpresa]: …No.  // buscando en el horizonte
NINA [calma]: Entonces no avisa.  // aplicando la frase del viejo al pie de la letra
[GESTO: Se queda mirando una nube con forma de silla.]
MASARU [en blanco]: …  // perdiendo el hilo ([en blanco]: se le apagó la atención)
[SFX: el viento de las alas pasa bajo, sobre el techo del hangar]
[ILUSTRACIÓN] Desde abajo, entre las cerdas de la escoba: Edda en el aire, contra el atardecer, sonriendo con toda la cara.
NINA [sorpresa]: Arriba sonríe. [EFECTO: frase clave]  // descubriendo algo que no sabe nombrar
MASARU [sorpresa]: ¿Quién?  // volviendo de la nube
NINA [calma]: Nadie. Anota que hay viento.  // guardándose lo que vio
[ENTRA: Edda, derecha]
[GESTO: Se saca el casco. Ya no sonríe. Abre una lata.]
EDDA [cansancio]: ¿Qué anotaste, entrenador?  // volviendo al piso
MASARU [ganas]: Que vuelas. Y que hay viento. Y una vaca.  // entregando su informe completo
EDDA [aburrimiento]: Muy útil.  // despachando el informe
[GESTO: Mira el cielo vacío donde estaba el ala.]
NINA [concentración]: ¿Qué se verá desde allá? [EFECTO: susurro]  // preguntándose algo por primera vez
[SALE: Edda]
[SALE: Masaru]
[SALE: Nina]
[MÚSICA: se apaga]
```
