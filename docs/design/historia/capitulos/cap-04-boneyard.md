## Historia principal · Capítulo 4 · Chatarra con alas

_Boneyard Works_
### Escena 1 · El taller

- **Objetivo:** Una última oportunidad de conseguir alas.
- **Obstáculo:** Parece un depósito de chatarra y nadie atiende.
- **Giro:** La chica del taller se entusiasma con la idea.
- **Salida:** Deciden construirlas.
```text
[FONDO: boneyard]
[MÚSICA: rock de garage en una radio mal sintonizada]
[NARRACIÓN]: Boneyard Works no tiene puerta: tiene un hueco en una pila de chatarra. Adentro suena una esmeriladora y alguien canta desafinado.
[ENTRA: Nina, izquierda]
[ENTRA: Masaru, centro]
[GESTO: Arrastra los pies.]
MASARU [cansancio]: Si acá también nos preguntan algo, me desmayo.  // arrastrando el cansancio
[GESTO: Esquiva una hélice tirada en el piso.]
NINA [concentración]: Si acá también es caro, me desmayo yo.  // acompañando el chiste
[ENTRA: Chica del taller, derecha]
[GESTO: Sale de abajo de un armazón, con grasa hasta en la cara.]
CHICA DEL TALLER [alegría]: ¡Hola! Cuidado con la hélice, muerde. ¿Están perdidos o vinieron a propósito?  // recibiendo como si los conociera
MASARU [sorpresa]: ¿Hay diferencia?  // preguntando en serio
[GESTO: Se limpia las manos en el pantalón. El pantalón queda peor.]
CHICA DEL TALLER [alegría]: Acá, no mucha. ¿Qué necesitan?  // haciéndolos sentir en casa
[GESTO: Cierra los puños para animarse.]
NINA [ganas]: Alas. De práctica. Las más baratas. Las más baratas de las baratas.  // juntando coraje
[GESTO: Ladea la cabeza.]
CHICA DEL TALLER [concentración]: ¿Para ti?  // midiéndola
NINA [sorpresa]: ¿Se nota que no vuelo?  // esperando el rechazo
CHICA DEL TALLER [alegría]: Se nota que quieres. Eso es lo difícil. Lo otro se arregla. [EFECTO: frase clave]  // viéndola de verdad
[GESTO: Abre el cuaderno, preparado.]
MASARU [concentración]: ¿Cuánto cuestan? Pregunto antes, por experiencia.  // protegiéndose de otro golpe
[GESTO: Señala la chatarra con una llave enorme.]
CHICA DEL TALLER [ganas]: Mira a tu alrededor. Todo esto es gratis. Lo difícil es que vuele.  // mostrando su tesoro
CHICA DEL TALLER [concentración]: Tú, el del cuaderno. Tráeme esa rueda del fondo.  // poniéndolos a trabajar
[GESTO: Mira el fondo: hay cuarenta ruedas.]
MASARU [sorpresa]: ¿Cuál de todas?  // perdiéndose otra vez
CHICA DEL TALLER [alegría]: La que te caiga bien.  // confiando en el azar
[SALE: Masaru]
```
### Escena 2 · La chapuza

- **Objetivo:** Armar alas con lo que haya.
- **Obstáculo:** Nada encaja con nada.
- **Giro:** Nina sirve para algo: deja las piezas como nuevas.
- **Salida:** Las alas existen.
```text
[SFX: una soldadora chisporrotea]
[ENTRA: Hombre de la soldadora, centro]
[GESTO: Levanta la careta de soldar.]
HOMBRE DE LA SOLDADORA [concentración]: ¿Qué inventaste ahora?  // desconfiando por experiencia
CHICA DEL TALLER [alegría]: Alas de práctica, jefe. Para ella. Con lo que haya.  // contagiando el plan
[GESTO: Mira a Nina de arriba abajo.]
HOMBRE DE LA SOLDADORA [concentración]: ¿Volaste alguna vez?  // midiéndola sin rodeos
NINA [en blanco]: …En sueños. ¿Cuenta?  // diciendo la verdad chiquita ([en blanco]: vergüenza)
HOMBRE DE LA SOLDADORA [calma]: Cuenta más de lo que crees.  // aprobándola a su manera
[GESTO: Baja la careta.]
HOMBRE DE LA SOLDADORA [aburrimiento]: Si se cae, que se caiga cerca del piso.  // dando permiso con cuidado
CHICA DEL TALLER [alegría]: ¡Eso es un sí!  // traduciendo al jefe
[NARRACIÓN]: Dos horas. Chispas, tornillos que no son de nada y una radio que solo agarra una estación.
[GESTO: Lija una pieza oxidada hasta que brilla.]
NINA [concentración]: ¿Así está bien?  // ofreciendo lo único que sabe hacer
[GESTO: Mira la pieza. Mira a Nina.]
CHICA DEL TALLER [sorpresa]: ¿Cómo la dejaste así? ¡Esta pieza tiene más años que yo!  // descubriendo su talento
NINA [alegría]: Limpio. Es lo único que sé hacer bien.  // achicándose sin querer
CHICA DEL TALLER [alegría]: Entonces ya tenemos a quien limpie el ala después de cada porrazo.  // dándole un lugar en el equipo
[GESTO: Mira un tornillo a contraluz.]
HOMBRE DE LA SOLDADORA [concentración]: Este tornillo es de un refrigerador.  // desconfiando de la obra
CHICA DEL TALLER [ganas]: Y va a volar.  // apostando por el atajo
HOMBRE DE LA SOLDADORA [aburrimiento]: Los refrigeradores no vuelan.  // poniendo los pies en la tierra
CHICA DEL TALLER [alegría]: Todavía.  // ganando la discusión
[SFX: el armazón cae de golpe sobre la mesa de trabajo]
[EFECTO: temblor]
NINA [sorpresa]: ¡Perdón! ¡No fui yo! …Creo que no fui yo. [EFECTO: texto rápido]  // pidiendo perdón por si acaso
[SALE: Hombre de la soldadora]
[ILUSTRACIÓN] Las alas de chatarra cuelgan de una cadena: una hélice vieja, una rueda, chapas de cinco colores distintos. El sol entra por los agujeros del techo y las atraviesa.
[ENTRA: Masaru, centro]
[GESTO: Entra con una rueda en los brazos y se queda quieto.]
MASARU [sorpresa]: …Eso es un ala.  // viendo lo imposible
CHICA DEL TALLER [alegría]: Son dos. Mira bien.  // corrigiéndolo con gusto
MASARU [ganas]: ¿Necesitan la rueda?  // queriendo haber ayudado
CHICA DEL TALLER [concentración]: Ya no. Pero déjala, me cae bien.  // aceptando lo que traiga
[GESTO: Descuelga las alas y se las apoya a Nina en los brazos.]
CHICA DEL TALLER [ganas]: Pruébatelas. Despacio.  // entregándolas sin ceremonia
> [ELECCIÓN] Qué le dice Masaru a Nina
> [ACEPTAR] Despacio. Como dijo ella.
> [RECHAZAR] ¿Y si pesan demasiado? Mejor mañana.
> [DESVIAR] ¿Hay casco? Para mí. Por si acaso.

(si ACEPTAR)
[GESTO: Se las pone con cuidado, una correa por vez.]
NINA [calma]: Despacio.  // obedeciendo

(si RECHAZAR)
[GESTO: Se las pone de un tirón.]
NINA [fastidio]: No. Hoy.  // negándose por primera vez

(si DESVIAR)
[GESTO: Le pone una olla en la cabeza.]
CHICA DEL TALLER [alegría]: Para ti hay una olla.  // riéndose de él
[GESTO: Se las pone mientras se ríe.]
NINA [alegría]: Te queda bien.  // riéndose también
[GESTO: Se tambalea con las alas puestas.]
NINA [alegría]: Pesan como un armario.  // diciendo lo obvio con felicidad
CHICA DEL TALLER [alegría]: Un armario que vuela. Vas a ver.  // prometiendo sin dudar
[GESTO: Grita desde el fondo del taller.]
HOMBRE DE LA SOLDADORA [concentración]: ¡Caracara! ¡Mañana a las seis hay entrenamiento! ¡No te olvides!  // llamándola desde el fondo
[NOMBRE: Chica del taller → Caracara]
[GESTO: Grita hacia el fondo, sin darse vuelta.]
CARACARA [alegría]: ¡Ya sé, jefe!  // contestando sin darse vuelta
[GESTO: Abraza las alas de chatarra.]
NINA [alegría]: Muchas gracias. Muchas. Mañana vengo a limpiarles el taller entero.  // agradeciendo de más
CARACARA [alegría]: Mañana entreno. Ven pasado.  // aceptando sin darle importancia
[SALE: Caracara]
```
### Escena 3 · De vuelta

- **Objetivo:** Volver a Vuela Alto con las alas.
- **Obstáculo:** Ninguno: van felices.
- **Giro:** No saben con quién estuvieron.
- **Salida:** Mañana a las seis empieza algo.
```text
[FONDO: exterior]
[MÚSICA: tema de Vuela Alto, ahora con batería]
[GESTO: Camina torcida por el peso de las alas.]
NINA [alegría]: Qué amable la chica del taller.  // volviendo feliz
MASARU [concentración]: Mucho. ¿Cómo se llamaba?  // dándose cuenta tarde
NINA [en blanco]: …No le pregunté. [EFECTO: globo que tarda]  // dándose cuenta también ([en blanco]: vergüenza)
MASARU [en blanco]: Yo tampoco.  // compartiendo la culpa
[NARRACIÓN]: En la radio de un auto que pasa, alguien anuncia el entrenamiento abierto de Caracara, la estrella de Boneyard, mañana a las seis.
NINA [ganas]: Mañana a las seis empiezo a volar.  // decidiendo
MASARU [cansancio]: Mañana a las seis yo duermo.  // cerrando con su verdad
```
